Regras

  • Linha de 56px dentro de k-table num k-card; cabeçalho em caption; divisórias line; hover surface-hover.
  • Miniatura 56×36: frame real quando existe; senão k-thumb neutro com play. As variantes is-dark e is-accent existem no CSS mas a fonte não diz quando usar — use o neutro até o Carlos dizer.
  • Título corta com reticências, nunca quebra. Aqui o título é o tema do vídeo até o primeiro “ — ” ou “ (” (o banco não tem um campo de título limpo — ver handoff.md).
  • Coluna Responsável (do desenho do Carlos) não aparece: nenhum dado diz quem está com cada vídeo.
  • Em tela estreita a tabela rola dentro do card (região com foco e nome para leitor de tela); a página não.
