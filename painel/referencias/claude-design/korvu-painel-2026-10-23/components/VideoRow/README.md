# VideoRow

Linha de vídeo dentro de `k-table` num `k-card`. Altura `row-height` (56px).

Colunas recomendadas: Vídeo (thumb 56×36 + título `body-strong` + formato · duração) · Responsável · Etapa · Progresso (`k-steps`) · Publicação · Estado (`k-chip`).

- Cabeçalhos em `caption`; divisórias `line`; hover `surface-hover`.
- Thumb: frame real do vídeo quando existe; senão `k-thumb` neutro com ícone `play`.
- Títulos longos cortam com reticências — nunca quebram em várias linhas.
