# StatusChip

Chips totalmente arredondados (`radius-pill`), 24px, sempre com palavra — a cor nunca é a única pista.

| Estado | Classe | Cor |
|---|---|---|
| Aprovado | `k-chip--aprovado` | `positive` sobre `positive-soft` |
| Em produção | `k-chip--producao` | `accent-ink` sobre `accent-soft` |
| Bloqueado | `k-chip--bloqueado` | `danger` sobre `danger-soft` |
| Agendado | `k-chip--agendado` | `ink-2` sobre `surface-sunken` |
| Publicado | `k-chip--publicado` | `bg` sobre `ink` (estado final) |
| Portão | `k-chip--portao` | contorno `accent`, ícone `lock`, sem ponto |
| Sonnet | `k-chip--model` | mono, contorno `line-strong` |
| Opus | `k-chip--opus` | mono, `ink` sólido (modelo mais caro = mais peso) |

Verde e vermelho só aparecem aqui e em métricas — nunca como decoração.
