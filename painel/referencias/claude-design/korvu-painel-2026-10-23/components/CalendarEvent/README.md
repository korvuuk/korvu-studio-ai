# CalendarEvent

Evento no calendário editorial: `k-event` (raio 6px, `surface`, borda `line`).

- Marca de canal: barra de 3px à esquerda — Instagram `k-event--ig` (`accent`), Facebook `k-event--fb` (`chart-5`), multicanal sem modificador (`ink`).
- Portões no calendário: `k-event--gate` (fundo `accent-soft`, texto `accent-ink`).
- Conteúdo: título (12px/600) + hora · canal (12px `ink-2`), uma linha cada, com reticências.
