# Logo

O logótipo é a palavra **`korvu.`** (Geist 800, tracking −4%) seguida de **`painel`** (Geist 500) num tom mais apagado.

- Sobre fundos claros (`bg`, `surface`): `korvu.` em `ink`, `painel` em `ink-2` — ficheiro `assets/Logos/korvu-painel-ink.svg`.
- Sobre a sidebar ou qualquer fundo `sidebar`: `korvu.` em `sidebar-ink`, `painel` em `sidebar-ink-2` — `korvu-painel-ivory.svg`.
- Em código use `Korvu.logo(altura, "ink" | "ivory")` ou `<span data-logo="ivory" data-h="19"></span>`.
- Altura mínima 16px. Área de respiro à volta = altura do `k`.
- Nunca colorir o logótipo de laranja, nunca separar `korvu.` de `painel` dentro do produto.
