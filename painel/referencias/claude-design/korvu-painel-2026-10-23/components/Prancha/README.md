# Prancha

A prancha 16:9 que reúne todo o design system numa só vista (1920×1080, exportada a 2560×1440 em `assets/Prancha/`).

Use-a como referência rápida antes de desenhar qualquer tela: logo, escala tipográfica, paleta, grid, espaçamento, raios, botões, chips, ícones, avatares, KPI cards, gráficos, linhas de vídeo, portão de aprovação, calendário, notificação, pesquisa, dropdown, tooltip, empty state e a sidebar final. Quando um token ou componente muda, a prancha muda com ele.
